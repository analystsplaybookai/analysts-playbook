# Sample Project (fictional)

A complete example of the folder the Analyst's Playbook builds, using a fictional HVAC
company. Every name and number here is invented for illustration.

- `01_deliverables/` — what the analyst shares (the pre-read brief).
- `_analyst-only/` — interview answers, run log, scorecard, cost plan and audit. Never shared.

Notice what is *not* in the brief: no costs, no prompt IDs, no mention of AI, no held findings.
